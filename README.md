## 🛰️ Sobre a missão

A missão responsável pela manutenção do módulo habitacional em órbita, garantindo que os sistemas vitais da tripulação permaneçam estáveis. Este repositório contém o software de bordo que verifica, em tempo real, as condições básicas de suporte de vida do módulo
